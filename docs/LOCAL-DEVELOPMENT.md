# LUMÉ CANDLES

Визуальная версия от 22 октября 2026: [отчёт о переработке, сохранности и проверках](docs/REDESIGN.md). В оформлении используются локальные Cormorant Garamond и Manrope и побайтовые копии исходных фотографий через `src/lib/photography.ts`, без повторной компрессии. Инструкции по последующей замене профессиональными кадрами находятся в отчёте. API, тарифы и хранилище корзины сохранены.

Локальный сайт-каталог свечей на Next.js App Router, React, TypeScript и Tailwind CSS. Все файлы находятся в этой папке. Node.js 24+, npm. Интернет для просмотра страниц не требуется после установки зависимостей.

## Запуск

```powershell
Set-Location 'B:\Neyro\ChatGPT_Codex\Project\14_Свечи'
npm ci
Copy-Item .env.example .env.local
npm run dev
```

Откройте http://localhost:3014 . Если `.env.local` уже существует, сохраните его настройки вместо повторного копирования. По умолчанию `ORDER_MODE=test`, база создаётся в `data/lume.sqlite`. В тестовом режиме вводите только вымышленные контакты. Telegram не вызывается.

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npm start
```

Для `npm start` предварительно остановите dev-сервер на том же порту. Порт и адрес можно изменить в `package.json`. Для E2E запустите сервер отдельно, затем `npm run test:e2e`. Тесты используют установленный Microsoft Edge, в том числе для эмуляции мобильного экрана. Перед повторными прогонами используйте отдельную тестовую SQLite-базу через `SQLITE_PATH`, чтобы ограничения частоты из предыдущих прогонов не мешали проверке.

## Что реализовано

- Главная, каталог, 12 страниц форм, мастерская, доставка, оплата, контакты, корзина, оформление и юридические черновики.
- Поиск, категории, фильтры по типу/технологии/декору, сортировка и пустое состояние. Неподтверждённые свойства не приписываются товарам.
- Конструктор: размер, материал, доступные ароматы, дополнительный декор, количество. Все значения считаются целыми рублями.
- Сохранение корзины в localStorage, объединение одинаковых конфигураций, отдельные варианты одной формы, редактирование и удаление.
- Серверная Zod-проверка, пересчёт стоимости, проверка доступности, PostgreSQL для реального режима, SQLite для локальных тестов.
- Уникальные номера, idempotency key, ограничение тела запроса, проверка Origin, HMAC-токен, honeypot, устойчивое ограничение частоты.
- Telegram Bot API только на сервере, долговечная очередь уведомлений в записи заказа, повторные попытки через закрытый endpoint.
- Responsive CSS, клавиатурные состояния, reduced motion, metadata, Open Graph, sitemap и robots. Демоверсия закрыта от индексации.
- 40 оптимизированных WebP и 40 маленьких превью. Оригиналы в `фото` не изменены.

## Важный статус проекта

Это проверяемая демонстрационная реализация, а не запущенный коммерческий магазин. 12 форм определены визуально и названы описательно. Они имеют `approved: false` и `optionsStatus: 'test'`. Материалы и размерные диапазоны в конструкторе показывают тарифную механику из ТЗ, но не подтверждают технологическую возможность каждой комбинации. Список ароматов пуст. Остальные фотографии находятся в обзоре исходников и не выданы за 28 дополнительных товаров.

Изображения приведены к единому размерному пределу без генеративного изменения изделий, удаления надписей или замены фона. Разные исходные фоны сохранены честно. Права, принадлежность фотографий и соответствие реальным изделиям необходимо подтвердить до публикации. Белофоновую фотосъёмку/обработку следует проводить отдельно после подтверждения прав и с визуальной приёмкой каждого изделия.

Полезные файлы: [каталог медиа](docs/media-catalog.html), [наполнение](docs/CATALOG.md), [Telegram и развёртывание](docs/DEPLOYMENT.md), [проверки](docs/TESTING.md), [решения клиента](docs/CLIENT-DECISIONS.md).

## Архитектурные ограничения

Для локального запуска не нужны PostgreSQL, Prisma или Docker. В реальном режиме PostgreSQL обязателен. Таблицы создаются приложением через `CREATE TABLE IF NOT EXISTS`; дальнейшие изменения схемы требуют версионированных миграций. Полноценной административной панели и открытого API чтения заявок нет. Для обслуживания базы используйте защищённые инструменты инфраструктуры и ограниченный доступ.

Уведомления имеют семантику at-least-once: после сетевой неопределённости Telegram может получить повтор с тем же номером. Дубликат уведомления не создаёт дубликат заявки. Для автоматических повторов необходимо настроить планировщик; без него очередь сохранится, но сама по таймеру не обрабатывается.

Ограничение частоты - базовая защита, не полноценная антибот-платформа. Перед открытием для публики настройте reverse proxy, его лимиты и при необходимости challenge. `TRUST_PROXY=true` допустим только если прокси перезаписывает `X-Forwarded-For`. Иначе все посетители используют общий защитный лимит.
