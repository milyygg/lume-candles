## Запуск у себя

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3014. Для GitHub Pages: `npm run build:pages`. Готовая сборка: `.pages-build/out`, ветка публикации: `gh-pages`.

Технологии: Next.js, React, TypeScript, Tailwind CSS.
