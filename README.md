# LUMÉ CANDLES

Сайт-каталог декоративных свечей ручной работы: коллекция, выбор размера, материала, аромата и декора, сохранённая корзина и согласование заказа через Telegram.

Для открытия сайта используйте существующий файл **Открыть сайт.url**. Он ведёт на https://milyygg.github.io/lume-candles/. Адрес и принцип запуска сохранены.

## Локальный просмотр

Нужен Node.js 24. В Windows PowerShell используйте `npm.cmd`, чтобы не менять политику выполнения сценариев.

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте http://localhost:3014. Для проверки готовой серверной сборки: `npm.cmd run build`, затем `npm.cmd start`.

## Публикационная сборка

`npm.cmd run build:pages` создаёт `.pages-build/out` для существующего адреса GitHub Pages. Публикация является отдельным действием; сборка сама ничего не отправляет в GitHub.

На статическом хостинге оформление подготавливает сообщение с составом корзины. Покупатель копирует его и отправляет в Telegram самостоятельно. Сайт не показывает фиктивное подтверждение отправки.

Серверные API и механизмы хранения заявок сохранены. Серверная форма включается через `NEXT_PUBLIC_CHECKOUT_MODE=server` после настройки окружения согласно [DEVELOPMENT.md](DEVELOPMENT.md).
