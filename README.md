# LUMÉ CANDLES

Сайт-каталог свечей ручной работы: коллекция, настройка изделия, корзина и подготовка заказа для отправки в Telegram.

**[Посмотреть онлайн](https://milyygg.github.io/lume-candles/)**

## Запуск

Node.js 24+: `npm ci`, затем `npm run dev`. Адрес: http://localhost:3014.

GitHub Pages: `npm run build:pages`. Сборка: `.pages-build/out`, ветка: `gh-pages`.
