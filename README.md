# LUMÉ CANDLES

[Открыть сайт](https://milyygg.github.io/lume-candles/)

Каталог декоративных свечей: коллекция, настройка изделия и корзина. Адаптирован для телефона и компьютера.

На GitHub Pages опубликована демонстрационная версия. Заявки, оплата и отправка в Telegram не подключены.

## Разработка

Node.js 24+.

```sh
npm ci
npm run dev
```

Локальный адрес: http://localhost:3014

## Публикация

```sh
npm run build:pages
```

Готовый сайт находится в `.pages-build/out`. Содержимое публикуется в ветке `gh-pages`, GitHub Pages использует эту ветку и папку `/`.

Серверная версия сохранена в исходниках. Подробности: [локальная разработка](docs/LOCAL-DEVELOPMENT.md).
